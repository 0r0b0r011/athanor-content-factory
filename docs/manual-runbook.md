# Manual Runbook

## Phase 0: Manual White-Glove Pilot

Before automating anything, run 3 pilots entirely by hand to discover the real workflow.

### Pilot candidates

1. **Moon as Timekeeper** — age 6–8, concept: moon phases as timekeeping
2. **Beastarium / Creature Classification** — age 9–12, concept: biological classification
3. **House of Patterns** — age 13–15, concept: mathematical pattern recognition

### Procedure for each pilot

1. Write `00_intent.yaml` by hand
2. Research the concept thoroughly → `01_research_pack.md`
3. Analyse developmental fit → `02_developmental_fit.yaml`
4. Construct the genome → `03_content_genome.yaml`
5. Design resonance strategy → `04_resonance_spec.yaml`
6. Build the world → `05_world_bible.md`
7. Develop characters → `06_character_bible.md`
8. Plan episode structure → `07_episode_timeline.yaml`
9. Adapt for each format → `08_format_plan.yaml`
10. Plan assets → `09_asset_manifest.yaml`
11. Write QA report → `11_qa_report.md`
12. Publish → `12_publish_manifest.yaml`

### What to learn

- Which stages produce the most value?
- Which stages are hardest to execute?
- What does a good genome look like in practice?
- What's missing from the process?
- Where do humans disagree with the schemas?

### After each pilot

Update the runbook with lessons learned. Patch the schemas if they don't match reality.
