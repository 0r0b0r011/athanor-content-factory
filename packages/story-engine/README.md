# Story Engine

Narrative structure generation: world bible, character bible, and episode timeline.

## Inputs

- `03_content_genome.yaml`
- `04_resonance_spec.yaml`

## Outputs

- `05_world_bible.md`
- `06_character_bible.md`
- `07_episode_timeline.yaml`

## Worldbuilding rules

1. The educational concept must be causally part of the world's laws
2. If the concept can be removed and the story still works, reject the world
3. The world must provide opportunities for discovery and practice

## Required archetypes

| Archetype | Function |
|-----------|----------|
| Seeker | Asks questions, drives curiosity |
| Keeper | Holds knowledge, reveals at the right time |
| Maker | Applies understanding to build/create |
| Listener | Represents the learner's perspective |
| Trickster | Creates puzzles, reveals through misdirection |
| Witness | Observes and reflects |
| Rival (without cruelty) | Challenges, motivates growth |
| Threshold Guide | Appears at transitions, provides frameworks |

## Episode beat structure

1. Opening ritual — stabilise world and learner
2. Wonder trigger — open curiosity gap
3. Failed attempt — surface misconception
4. Concept reveal — present correct model
5. Aha moment — knowledge resolves conflict
6. Retrieval — active recall
7. Transfer — apply to new context
8. Closing ritual — stabilise and seed next
